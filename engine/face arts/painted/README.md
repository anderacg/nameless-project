# Redrawn portrait parts

The user-approved earless human male base is installed unchanged as `heads-human-male.png`. Seven matching redraws supply human female, dwarf male/female, orc male/female and elf male/female bases in `heads-human-dwarf-orc.png` and `heads-orc-elf.png`. Their rounded crowns, natural jaws and curved necks replace the old five head masters. No legacy jaw clipping, ear inpainting, erosion or neck-backing patches remain in the active head renderer.

The renderer has **53 active painted components**, including **8 redrawn head bases**, assembled into **19 independent layers**. All existing face selectors and proportion controls remain: the eight authored bases are fitted to 64 race/profile/face-shape combinations. This is eight new authored skin masters with dynamic variants, not 64 independently painted source images. Eyes, noses, mouths, ears, hair, beards, marks and equipment remain separate. Saved version-7 recipes and character identities are unchanged.

`parts-manifest.json` records original PNG hashes, tight visible rectangles and each head's race/profile/reference geometry and color. The original `parts-faces.png` retains its old first five frames as source history; `activeFrames` excludes them. Its other 20 components and the 25 equipment components remain active. The five packaged PNG atlases contain 58 frames in total, of which 53 are active. The new PNGs are unchanged generator outputs. Import ignores near-transparent fringes; each new master has a single visible connected component.

Head rendering samples RGB and alpha together through the same shape transform. Reference-head aspect ratio is preserved; bounded deformation follows existing face/jaw controls. The authored neck is blended into the common collar width and fitted below the shoulder line to the body footprint. There is no second mask reshaping the jaw. Separate ears supply all ear artwork; their roots translate to the actual new skin edge without resizing the ear sprites. Facial detail and short stubble are clipped to the active skin; full beards keep their own silhouette.

Composition draws skin and its detail before clothing/armor, then front hair/headwear and beards. Equipment therefore covers neck skin instead of being painted over by it. `PortraitArtwork.order` exposes this order. Both editor part exports include the actual draw order while retaining their existing atlas frame positions.

Load `../grayscale/portrait-engine.js`, `painted-data.js`, then `painted-engine.js`; await `PortraitArtwork.ready`. `PortraitArtwork.render(config,{colors})` returns a composite; `build(config,{colors,size:256})` returns independent RGBA layers, source-head identity and the unchanged rig anchors. `composite(p,{visible})` supports toggles. Sizes 128, 256 and 512 remain supported. Artwork API version is 2; recipe version remains 7.

The game and wiki use locally bundled image data, with no image-generation service at runtime. Existing procedural loading fallback remains. The parent `../portrait-workshop.html` preserves player reservation, NPC generation, favorites and collection import/export; `portrait-workshop-painted.html` is the focused 256-pixel editor. Both export the current painted art.

Run `python ../build.py` here to rebuild local data and all portable editors. `workshop-adapter.js` preserves the full studio's existing character API. Asset PNGs should remain unchanged; edit the manifest/renderer and regenerate bundles when updating source artwork.

Facial expressions retain all current eye/mouth forms. Orc lips and independent ivory tusks keep their prior refinements. Age and complexion marks inherit local skin texture with shallow relief; their choices and seven tint channels remain dynamic. Armor material fitting retains its collar alignment and original geometry.
